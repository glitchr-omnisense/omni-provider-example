# omnimap/example

> A throwaway package: the provider template's example, generated by `bin/init omnimap example "Example Tiles"`, on which the release workflow is proved. Not published on Packagist; not for use.

Example Tiles for [omniscient/omnimap](https://github.com/glitchr-studio/omnimap), under any PHP host.
Plain PHP: no framework in `require`.

```php
use Omnimap\Example\ExampleFactory;

$provider = (new ExampleFactory())->create([/* options: docs/index.md */]);
```

With the family's `Registry`, by its factory name `example`:

```php
$registry = new Omnimap\Registry([new ExampleFactory()], ['main' => ['factory' => 'example', 'options' => []]]);
```
